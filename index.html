MORPH LAB / QUICK GUIDE

From a harmonic to a whole new sound.

  1. Sculpt. Move any of the 64 amplitude or phase sliders. Changes create a keyframe at the selected frame.
  2. Morph. Add keyframes, choose linear, cosine or Hermite interpolation, then scan through the table.
  3. Draw. Enable drawing and sketch on the waveform. A periodic spline connects 32 handles. Apply it to convert to 64 harmonics.
  4. Listen. Hold the on-screen keys or A–K keyboard notes. Hold tone sustains C at the selected octave. Audio starts only after interaction.
  5. Export. Download float WAV, an embedded C/C++ array, or a JSON project you can reopen.

WAV import uses the specified cycle length. Use a known single cycle or packed table; ordinary recordings need cycle preparation. modwave exports retain at most 64 evenly spaced frames.

Edits autosave to this browser. Save a JSON preset for a portable backup. Ctrl/⌘ Z undoes; Ctrl/⌘ Shift Z redoes.
